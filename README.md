# ParkSmart UMBC

A web app that helps UMBC students find parking faster and with less guesswork.

## The Problem

Finding a spot on campus is stressful, especially around peak class times. Students circle lots, show up late, and have no easy way to know where space is available before they arrive.

## Vision

ParkSmart aims to give students a clear, real-time picture of campus parking so they can decide where to park before they leave home. The goal is to reduce time spent searching for a spot, cut down on late arrivals, and make better use of the lots UMBC already has.

## Approach

- **Student-first:** designed around how UMBC students actually commute and park.
- **Web-based:** a responsive web app that works on phones and laptops with nothing to install.
- **Built for campus:** developed with and deployed through the DAMS Research Lab (UMBC Smart Campus), so it can connect to campus infrastructure over time.

## Planned Architecture

- **Frontend:** React and Next.js with TypeScript
- **Backend and data:** Supabase for the database, authentication, and real-time updates
- **Deployment:** hosted through the DAMS Lab environment

## Roadmap

**Current status: Beta**

| Phase | Focus | Status |
|-------|-------|--------|
| 1 | Core app: lot listings and basic availability view | In beta |
| 2 | Student accounts and saved preferences | Planned |
| 3 | Real-time availability updates | Planned |
| 4 | Smart Campus / IoT sensor integration with DAMS Lab | Exploring |
| 5 | Predictions, such as the best lot for a given time of day | Future |

## Goals for Beta

- Gather feedback from UMBC students on what's useful
- Validate that the availability data is accurate enough to trust
- Identify the most-requested features to prioritize next

## Future Ideas

- Notifications when a preferred lot opens up
- Historical trends to show the busiest times
- Accessibility and visitor parking support
